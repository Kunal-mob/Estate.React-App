## 🏠 Overview

Estate React App is a modern real estate application built with React.js and Vite. It provides a seamless user experience for browsing, managing, and exploring property listings with a clean, responsive interface.

## ✨ Features

- ⚡ **Lightning Fast** - Built with Vite for instant HMR (Hot Module Replacement)
- 🎨 **Responsive Design** - Mobile-first approach with CSS styling
- 📱 **Modern UI** - Clean and intuitive user interface
- 🔧 **Easy to Extend** - Modular component architecture
- 🎯 **ESLint Ready** - Pre-configured linting for code quality

## 🚀 Getting Started

### Prerequisites

- Node.js 16.0.0 or higher
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Kunal-mob/Estate.React-App.git
   cd Estate.React-App
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

## 💻 Development

Start the development server with HMR enabled:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### ESLint Configuration

The project includes ESLint rules for code quality. For production applications, consider enabling TypeScript with type-aware lint rules for enhanced type safety and error detection.

## 🏗 Build

Create an optimized production build:

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory, ready for deployment.

### Preview Production Build

```bash
npm run preview
```
